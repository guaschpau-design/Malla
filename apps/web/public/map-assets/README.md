# Map assets

Glyphs and sprites for the Protomaps basemap style, vendored so the map works fully offline.

Source: <https://github.com/protomaps/basemaps-assets>

| Folder     | Content                                                                                                                                               | Licence                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `fonts/`   | Noto Sans Regular, Medium and Italic glyphs, only the Unicode ranges used by European languages (Latin, Latin Extended, Greek, Cyrillic, punctuation) | SIL Open Font License, see `fonts/OFL.txt`                                                           |
| `sprites/` | Light and dark sprite sheets, version 4                                                                                                               | Derived from MIT-licensed [tangrams/icons](https://github.com/tangrams/icons/blob/master/LICENSE.md) |

Characters outside the vendored ranges are simply not drawn; add a range here if a region needs it.
