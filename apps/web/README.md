# @tesel/web

The Tesel progressive web app: map and offline areas, identity and groups, the event log and its sync with the group's server, live positions, chat, map objects, SOS and alerts.

| Path                             | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/App.svelte`                 | Application shell: top bar, map and panels                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `src/import-cycles.test.ts`      | Keeps modules from importing each other in a cycle                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `src/lib/map/`                   | The map view, its controls and layers panel, overlays, taps (one dispatcher for every layer) and the framing at start ([ADR-0054](../../docs/decisions/0054-frame-the-group-at-start.md))                                                                                                                                                                                                                                                                                                                     |
| `src/lib/map/style/`             | Base maps and their style: the street and topographic flavours, contour lines, map images, credits and MapLibre's own texts ([ADR-0034](../../docs/decisions/0034-vector-topographic-map.md), [ADR-0035](../../docs/decisions/0035-base-maps-by-purpose.md))                                                                                                                                                                                                                                                  |
| `src/lib/map/tiles/`             | Where tiles come from and how they are read (one protocol), the offline tile store and its schema, area downloads, the satellite mosaic and national photographs ([ADR-0011](../../docs/decisions/0011-client-side-area-download.md), [ADR-0023](../../docs/decisions/0023-ign-base-maps.md), [ADR-0037](../../docs/decisions/0037-maps-across-borders.md), [ADR-0041](../../docs/decisions/0041-satellite-mosaic-and-national-photos.md), [ADR-0056](../../docs/decisions/0056-storage-and-offline-maps.md)) |
| `src/lib/offline/`               | Offline maps panel, what a download holds and how fast it asks each source, and the download's progress                                                                                                                                                                                                                                                                                                                                                                                                       |
| `src/lib/terrain/`               | Elevation tiles, the climb of a way ([ADR-0037](../../docs/decisions/0037-maps-across-borders.md))                                                                                                                                                                                                                                                                                                                                                                                                            |
| `src/lib/position/`              | This device on the map, its GPS and accuracy, and sharing, pausing or hiding its position (the Me panel)                                                                                                                                                                                                                                                                                                                                                                                                      |
| `src/lib/coordinates/`           | Coordinate formats, the MGRS grid, a point of the map and finding a typed coordinate ([ADR-0021](../../docs/decisions/0021-coordinate-formats.md))                                                                                                                                                                                                                                                                                                                                                            |
| `src/lib/navigation/`            | Guidance to a point, object or member                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `src/lib/measure/`               | Measuring distances and areas on the map                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `src/lib/identity/`              | This device's key pair and alias; first-launch dialog                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `src/lib/groups/`                | Groups panel, roles, invitations (QR, link, camera scan) and joining ([ADR-0012](../../docs/decisions/0012-invitation-links-under-a-base-path.md))                                                                                                                                                                                                                                                                                                                                                            |
| `src/lib/members/`               | A group's members: what to call them, the list, their details, and their positions and trails on the map                                                                                                                                                                                                                                                                                                                                                                                                      |
| `src/lib/storage/`               | The app's IndexedDB database (identity, groups, settings, events, outbox, sync cursors, servers, radio texts, weather warnings)                                                                                                                                                                                                                                                                                                                                                                               |
| `src/lib/settings/`              | The device's preferences: map, layers, coordinate format, screen                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `src/lib/events/`                | Each group's event log, own sequence numbers and the outbox (the events waiting for the server), kept in IndexedDB by `event-log.ts`                                                                                                                                                                                                                                                                                                                                                                          |
| `src/lib/sync/`                  | The group feed (`group-feed.svelte.ts`), which ties the active group's log to the relay and the radio; the relay client, the order of relays and the cursors (protocol §8); what a radio is given when it connects (`lora-events.ts`); saving and loading log files (`log-file.ts`)                                                                                                                                                                                                                           |
| `src/lib/links/`                 | How the device reaches its group (WiFi, mobile data, LoRa, command post): the top-bar indicator and the connections panel                                                                                                                                                                                                                                                                                                                                                                                     |
| `src/lib/radio/`                 | The LoRa radio: pairing, the active group's channel, feeding events through the airtime scheduler of `packages/core`, other MeshCore apps' texts                                                                                                                                                                                                                                                                                                                                                              |
| `src/lib/chat/`                  | Group chat panel, with alerts ([ADR-0026](../../docs/decisions/0026-one-kind-of-alert.md)) and dictation ([ADR-0040](../../docs/decisions/0040-dictated-messages.md))                                                                                                                                                                                                                                                                                                                                         |
| `src/lib/objects/`               | Markers and areas: drawing, map layers, details, the warning on entering a danger area ([ADR-0033](../../docs/decisions/0033-danger-area-warning.md))                                                                                                                                                                                                                                                                                                                                                         |
| `src/lib/tasks/`                 | Tasks: list, form with the common tasks, and map layer ([ADR-0025](../../docs/decisions/0025-tasks.md))                                                                                                                                                                                                                                                                                                                                                                                                       |
| `src/lib/services/`              | Public services of the base map: icons and taps ([ADR-0027](../../docs/decisions/0027-public-services-from-the-base-map.md))                                                                                                                                                                                                                                                                                                                                                                                  |
| `src/lib/cadastre/`              | The cadastre's parcels, one picture of the view at a time ([ADR-0036](../../docs/decisions/0036-cadastre-layer.md))                                                                                                                                                                                                                                                                                                                                                                                           |
| `src/lib/weather/`               | Official weather warnings: the server's feed kept on the device, the map layer, the card where you are ([ADR-0030](../../docs/decisions/0030-weather-warnings.md))                                                                                                                                                                                                                                                                                                                                            |
| `src/lib/incidents/`             | SOS calls, alerts and acknowledgements                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `src/lib/practice/`              | Practice mode: a simulated group around the device, played on it ([ADR-0031](../../docs/decisions/0031-practice-mode.md))                                                                                                                                                                                                                                                                                                                                                                                     |
| `src/lib/radar/`                 | The radar: rings around this device by zoom, and lines to the nearest members                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `src/lib/diary/`                 | The operation diary, and the panel that saves and loads the group's log files ([ADR-0022](../../docs/decisions/0022-log-files.md))                                                                                                                                                                                                                                                                                                                                                                            |
| `src/lib/workspace/`             | Everything on top of the map, wired to the active group: what is going on now (`MapStatus`), the dock and its menus, and the slices of state each layer redraws from                                                                                                                                                                                                                                                                                                                                          |
| `src/lib/ui/`                    | Shared building blocks: panel, dialog, confirmations, notices, switch, status dot, pictograms, QR code                                                                                                                                                                                                                                                                                                                                                                                                        |
| `src/lib/pwa/`                   | Service worker registration and update prompt                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `src/lib/i18n/`                  | Spanish and English texts; English defines the keys and which of them have plural forms                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `src/lib/session.svelte.ts`      | Reactive state of identity and groups that components read                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `src/lib/config.ts`              | Build-time settings: base map, server, guide, satellite mosaic                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `src/lib/format.ts`, `text.ts`   | Locale-aware numbers, dates and measures; cutting text between visible characters                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `public/map-assets/`             | Vendored glyphs and sprites, see its README for licences                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `e2e/`                           | End-to-end tests in a real browser                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `scripts/make-borders.py`        | Generates the outlines of Spain, Portugal and southern France where the satellite map lays each country's photographs                                                                                                                                                                                                                                                                                                                                                                                         |
| `scripts/third-party-notices.ts` | Writes `third-party-notices.txt` into the build: the licence of every third-party package the app ships, linked from the layers panel. Texts a package does not ship are kept in `scripts/notices/`                                                                                                                                                                                                                                                                                                           |

| Variable                | Meaning                                                                                                                                                                                                                                                                                                     |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VITE_BASEMAP_URL`      | PMTiles base map, absolute or relative to the app. Defaults to the Protomaps demo archive, for development only                                                                                                                                                                                             |
| `VITE_SERVER_URL`       | Server proposed for new groups, absolute or relative to the app; empty for none                                                                                                                                                                                                                             |
| `VITE_SATELLITE_MOSAIC` | The satellite map's mosaic from afar ([ADR-0051](../../docs/decisions/0051-satellite-mosaic-licence.md)): `s2cloudless-2024`, the default, is **free for non-commercial use only** (CC BY-NC-SA 4.0); a commercial deployment builds with `s2cloudless-2016` (CC BY 4.0) or licenses the newer one from EOX |
| `TESEL_BASE`            | Base path when served from a sub-folder, e.g. `/app/` in the server image (`apps/server/Dockerfile`)                                                                                                                                                                                                        |

```sh
pnpm dev        # development server
pnpm build      # production build in dist/
pnpm test:e2e   # end-to-end tests (Playwright Chromium required)
```
